⚠️ Important Notes

⚠️ Migration is One-Time Only!

Run migrate_passwords.php only once. The script will hash all existing plaintext passwords in the database.

ℹ️ Backup Before Migration

Always backup your database before running the migration script. This ensures you can rollback if something goes wrong.

ℹ️ Testing Required

Test login with existing accounts and signup with new accounts to ensure everything works correctly.
